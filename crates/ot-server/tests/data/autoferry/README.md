# Autoferry replay fixtures

Generated by `scripts/autoferry.py` from the Autoferry maritime sensor fusion
benchmark (NTNU, CC0): <https://github.com/mhelg/sensor_fusion_dataset>, described in
*Heterogeneous multi-sensor tracking for an autonomous surface vehicle in a littoral
environment* (Ocean Engineering, 2022).

- `scenarioN-tracks.jsonl`: the ground truth as a track feed (`track`), and lidar
  and radar detections run through a simple tracker (`lidar`, `radar`).
- `scenarioN-detections.jsonl`: the same track feed, and the raw detections
  (`lidar-det`, `radar-det`), clutter included.

Each line is `{"feed", "truth", "obs"}`, where `truth` is the target the report is nearest
to (within 30 m) or null for clutter. The engine's `replay_autoferry_*` tests score against it.
